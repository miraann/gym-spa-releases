# جیم و سپا · Gym & Spa: Windows installers

This repository holds only the Windows installers of Click Group's Gym & Spa app, as releases. There is no source code here.

- **The online edition's Windows app updates itself from the latest release here.** It downloads a new version in the background and installs it when staff press «نوێکردنەوە».
- **Only install a build that Click Group gave you.** The installers aren't code-signed yet, so Windows SmartScreen asks first: **More info → Run anyway**.
- The offline edition is not published here: it comes on a USB stick.

Each release holds `gym-spa-setup-<version>.exe`, its `.blockmap` files, and `latest.yml`, which tells the app the newest version and the installer's SHA-512.
